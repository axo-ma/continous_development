# Общая служба CD5 Continuator —31Oct2026

Реализована одна служба на учётную запись Windows для нескольких явно подключённых штабов. Она читает текущего владельца из канонического CHECKPOINT, два файла управления, занятость и свежую квоту, затем последовательно отправляет продолжение. Собственная цель CD5 остаётся в задачах и вехах штаба; native Goal не является драйвером.

## Установлено

- Общая служба и переносимый установщик. Одна скрытая команда HKCU Run при входе Windows, без модельного планировщика.
- Одна общая группа SessionStart/UserPromptSubmit/Interrupt; точное определение подтверждено пользователем.
- Передача настоящего подключения от штатного события Codex службе, не имеющей унаследованного Codex-окружения. Без подключения процесс ждёт без модели.
- Текущая память разработки очищена от действующих старых native-статусов; прежний CHECKPOINT, OUTLINE и профиль целиком сохранены в локальной истории.
- Старые диагностические материалы явно обозначены историческими. MAC сохраняет независимость и точную модельную проверку; native Goal как конкурирующий CD5-драйвер запрещена.

## Фактически проверено

- Полная проверка:255 тестов,0 ошибок. Включены два HQ, независимость флагов, текущий владелец, занятость, квота90, модельный запрет и единственность экземпляра при разных путях конфигурации.
- Живой отдельный процесс с очищенными CODEX-переменными сначала ждал, затем после регистрации настоящего подключения получил реальную квоту и обслужил два разрешённых корня. Занятый текущий штаб получил0 сообщений; технический сохранил полезный результат с независимо сверенным SHA256.
- Точная команда установленного HKCU Run запущена вручную без Codex-окружения. Настоящее событие UserPromptSubmit нового доверенного обработчика зарегистрировало подключение; процесс успешно подключился. Повторный запуск даже с другим путём конфигурации не создал второй экземпляр.
- Новая кнопка Stop: реальный ручной измерительный ход был interrupted, новый обработчик создал Stop Goal технического HQ. При обоих файлах и счётчике2 ниже независимого потолка3 служба сохранила stopped и не отправила третье сообщение. Исходное60-секундное ожидание закончилось без нажатия и не считается успешным Stop-тестом; успешное нажатие произошло в последующем ручном ходе.
- Работающий процесс прочитал изменённого владельца из тестового CHECKPOINT при сохранённом Stop; адрес старого чата не был зафиксирован навечно. Это контролируемая смена записи стенда без отправки в фиктивный чат, не полная передача рабочего штаба человеку-преемнику. Тестовая запись восстановлена.
- Технический HQ после проверок отключён от обслуживания, его Stop и история отправок сохранены. Научные и посторонние HQ не подключались.

## Пользование

Continue Goal создаёт Continue и снимает Stop. Stop Goal запрещает следующие запуски. Кнопка ■ прерывает текущий ход и дополнительно устанавливает Stop. При ожидаемом завершении, обязательном вопросе или квотной остановке сам HQ удаляет Continue. Сервис не определяет причины простоя.

## Пределы проверки

Реальный выход/вход в Windows и перезапуск Codex не выполнялись по условию задачи. Запись автозапуска и её точная команда проверены отдельно; не объявляются испытанием настоящего входа. При новом запуске Codex служба ждёт предоставления действительного подключения штатным событием подключённого HQ; простое открытие окна без такого события не считается доказанным подключением. Квотное восстановление и полный учёт вложенных агентов не добавлялись.

Личные REGISTRY/CONNECTION, управляющие файлы, журналы реальных чатов и credentials не включаются в публикацию.
