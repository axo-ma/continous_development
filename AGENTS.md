# Development rules

This repository is the canonical source for the Codex CD5/MAC skills. Edit `codex/skills` directly. Installed skills are deployment copies; do not develop in a user's installed directory or rebuild from an unrelated project's tools folder.

Run `python codex/run_tests.py` before publishing changes. Use temporary fixture projects; never import a user's journal/history into examples or tests. Keep MAC template settings neutral and preserve installed local settings during upgrades. No schedules, scientific work or project continuation are authorized by installation.

Documentation examples must be labelled synthetic. Update the offline example when report behavior changes. Forecasts, independently authorized limits and measured actual WU remain distinct; unknown measurements are not zero. Preserve canonical event history and the original forecast.
