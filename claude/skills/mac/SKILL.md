# MAC для Claude — работа с агентами

**MAC** (Multi-Agent Chat) — правила необязательного делегирования. Работает и без CD5, в любом чате. **Главный** — текущий чат (в проекте CD5 — штаб): он отвечает за задачу, собирает результат и принимает важные решения. Слишком мелкую работу не отдавать: задание и проверка дороже, чем сделать самому.

Проектные STOP, разрешения и бюджеты всегда сильнее MAC.

## Когда отдавать

- Независимый кусок, результат которого можно принять отдельно, и цена задания + проверки оправдана.
- Пачки независимых задач — параллельно.
- Длинные логи, чаты, transcript — читает агент в своём контексте; главному — выводы с цитатами.
- Рассуждение и решения — главный сам. Модель роли — в таблице ниже (`model` у `Agent`). Модель, которой нет, не обещать и молча не подменять.

## Роли и глубина

| роль | что делает | кто запускает | модель |
|---|---|---|---|
| исполнитель (executor) | законченный ограниченный результат: код, запуски | главный | Sonnet |
| проверяющий (reviewer) | независимо проверяет чужую работу | только главный | Opus |
| консультант (consultant) | мнение по трудному вопросу | только главный | Opus |
| помощник (helper) | один ограниченный шаг, простая механика | главный или основная роль, в своём бюджете | Haiku |

Проверяющий — Opus, а не слабее того, кто делал работу: иначе он не заметит ошибок сильной модели. Запускать его только на результат, который того стоит, а не на каждую мелочь.

- Глубина не больше: **главный → основная роль → помощник**.
- **Помощник никого не запускает.** Каждое задание помощнику прямо это запрещает.
- Исполнитель может попросить проверку или консультацию — запускает их главный.
- Подзадача (`start_session`) — это главный своего чата: внутри неё действуют те же правила.
- Если платформа не даёт сделать разрешённый вложенный запуск — сказать об этом, а не изобретать обход.

## Шаблон задания

Агент начинает с нуля, поэтому задание самодостаточное. Все пункты обязательны, даже для мелкого задания: «Бюджет» тогда — например, «один шаг, без помощников».

```
Цель: <что должно получиться>
Контекст: <проверенные факты, пути, памятка проекта для агентов, если есть>
Ограничения: <чего не делать; что не трогать>
Можно менять: <файлы/папки>; остальное — только читать
Результат: <что вернуть и в каком виде — коротко, без сырых логов>
Проверка: <как убедиться, что сделано>
Бюджет: <объём работы; сколько помощников можно и одновременно ли>
[для помощника] Других агентов не запускай.
```

## Приём результата

- Главный проверяет каждый результат по файлам и фактам, прежде чем показать пользователю; пользователю — разобранный итог, не сырой отчёт.
- **Самопроверка ≠ независимая проверка.** «Проверено независимо» — только если отдельный проверяющий реально смотрел работу.
- Работа агента — не решение пользователя и не «человеческая разметка».
- Помощник возвращает результат тому, кто его вызвал; его transcript главному не пересылать.
- Изменить бюджет задания — только через главного.
- Учёт расхода по участникам в этой версии не ведётся; неизвестные цифры — «неизвестно», не ноль.
