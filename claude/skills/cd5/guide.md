# Как работать со штабом CD5 (гайдлайн для пользователя)

Показывать целиком по просьбе «дай гайдлайн», «как работать со штабом».

**Главное:** в штабе вы думаете и решаете. Работу делают подзадачи, штаб следит за ними и приносит готовый итог. Всё важное штаб записывает в память проекта, поэтому новый штаб продолжает с того же места.

## Что на экране

```
папка проекта                      ← группа в боковой панели (папка на диске)
 ├─ <проект> HQ · 261024-1730      ← штаб: чат, где вы обсуждаете и решаете
 │   └─ Переобучение Splitter…     ← подзадача: её запустил штаб, работает сама
 └─ … другие чаты этой папки
```

Чат и сессия — одно и то же: строка в боковой панели. «Штаб» — наше слово для чата, который отвечает за проект.

## Обычный цикл

```
вы: «продолжай работу» → штаб: где мы + варианты следующего шага
вы: выбираете          → штаб: запускает подзадачу (появится строка под штабом)
        …можно уйти, подзадача работает сама…
подзадача закончила    → штаб: проверяет и показывает итог
вы: принимаете         → штаб: записывает факт, вывод и следующий шаг в память
```

## Полезные фразы

| что хотите | что сказать штабу |
|---|---|
| вспомнить, где остановились | «продолжай работу» / «где мы?» |
| остановить всё | «стоп» — штаб ничего не запустит, пока вы не скажете «продолжай» |
| увидеть вопросы, ждущие вас | «покажи внимание» |
| узнать, как идут подзадачи | «что с подзадачами?» |
| поправить план | правите `OUTLINE.md` руками или говорите штабу |
| штаб стал длинным, тема закончена | «обнови штаб» — откроется новый, старый уйдёт в архив после вашего «да» |
| не поняли ответ | «не понял» — штаб объяснит иначе |
| этот гайдлайн | «дай гайдлайн» |

## Память проекта

Пять файлов в папке `coordination/cd5` проекта. Руками правится только `OUTLINE.md` — план. Остальные пишет штаб через скрипт:
- `CHECKPOINT.json` — где мы сейчас и что дальше;
- `EVIDENCE.jsonl` — факты: прогоны, отчёты;
- `KNOWLEDGE.jsonl` — выводы, каждый со ссылкой на факт;
- `ATTENTION.jsonl` — вопросы к вам.

## Правила устройства

- **Один действующий штаб на проект** — он единственный пишет в память.
- **Два уровня:** штаб → подзадачи. Внутри подзадачи части работы делают агенты, а не новые чаты.
- **Штаб — чат верхнего уровня**, не вложенный в другой.
- **Ваше «стоп» сильнее всего:** его не снимают ни смена штаба, ни обновление навыка.
