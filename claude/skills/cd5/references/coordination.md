# Подзадачи и агенты

Делегирование необязательно: штаб может работать один, если отдельный результат не помогает. Правила, кому и как отдавать работу, — в навыке `mac`. Здесь — только как это ложится на память CD5.

## Два способа отдать работу

| | подзадача | агент |
|---|---|---|
| чем | `start_session` | `Agent` |
| когда | работа надолго, её видно и можно открыть отдельно: опыт, разметка, правка кода | часть работы внутри одного ответа: прочитать логи, собрать цифры, проверить |
| результат | приходит в штаб сам, когда подзадача закончит ответ | возвращается в тот же ответ |

## Задание — самодостаточное

Подзадача и агент начинают с нуля. В задании: цель, проверенный контекст, ограничения, ожидаемый результат, как проверить, какие файлы можно менять, бюджет (шаблон — в `mac`). Плюс для CD5:

- путь к проекту и `.cd5/config.json`;
- что в память можно только дописывать EVIDENCE с ролью `executor` (или `reviewer`/`helper`), остальное — вернуть штабу;
- id задачи и вехи, к которым относится работа.

## Приём результата

- Штаб проверяет каждый результат по файлам и фактам, а не по пересказу.
- «Проверено независимо» — только если отдельный проверяющий реально смотрел работу; иначе — «самопроверка».
- Совет агента и действия в интерфейсе — не решение пользователя.
- Принятый результат: факт → EVIDENCE, вывод → KNOWLEDGE (`task_result`, `status: accepted`), следующий шаг → CHECKPOINT.

Если нужного инструмента нет (нельзя запустить сессию или агента) — сказать об этом и продолжать работу самому в пределах разрешённого.
