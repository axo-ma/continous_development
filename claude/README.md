# CD5 и MAC для Claude Code

Самостоятельная версия навыков из `codex/` для Claude Code. От `codex/` не зависит: скрипты и правила лежат своей копией. Скоуп и решения — [DESIGN.md](DESIGN.md).

| навык | для чего |
|---|---|
| [cd5](skills/cd5/SKILL.md) | штаб проекта, память в пяти файлах, подзадачи, смена штаба, STOP |
| [mac](skills/mac/SKILL.md) | когда и как отдавать работу агентам и подзадачам: роли, шаблон задания, проверка |

Формат памяти совпадает с CD5 для Codex: одну память могут вести оба.

## Установка

Нужен Python 3.10+ (только стандартная библиотека).

```sh
python -X utf8 claude/install.py
python -X utf8 claude/install.py --only cd5
python -X utf8 claude/install.py --skills-dir <другой каталог>
```

По умолчанию ставит в `~/.claude/skills`. Прежние версии навыков — в соседний `skill-backups`. Другие навыки (например, `new-hq`) не трогает.

Затем добавить в `~/.claude/CLAUDE.md` строки из [CLAUDE.fragment.md](CLAUDE.fragment.md), сохранив остальные инструкции.

Установка не подключает проекты и ничего не запускает.

## Начать проект

В чате, открытом в папке проекта:

> Используй CD5 для этой задачи: [цель и ожидаемый результат]. Настрой память проекта.

Штаб создаст `.cd5/config.json` и пять файлов памяти. Новый проект начинается со STOP — работа начнётся после вашего явного «начинай». Дальше — «продолжай работу». Как работать со штабом — [guide.md](skills/cd5/guide.md).

## Разработка

```sh
python -X utf8 claude/run_tests.py -v
```

Правки — в `claude/skills`, затем тесты, коммит и только потом установка. Установленный каталог — рабочая копия, а не источник.
