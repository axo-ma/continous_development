# CD5 и MAC: установка и использование

## Что устанавливается

В `skills/cd5` и `skills/mac` находятся самостоятельные исходники двух навыков. Установка не переносит историю чужого проекта, не создаёт расписаний и не начинает работу. MAC в комплекте содержит чистые настройки; текущие настройки вашей установки сохраняются.

## Установка

Нужны Codex с поддержкой локальных skills и Python 3.10+. Выберите настроенный каталог навыков вашего Codex и выполните из корня репозитория:

```sh
python codex/install.py --skills-dir <каталог-навыков>
```

Только один навык:

```sh
python codex/install.py --skills-dir <каталог-навыков> --only cd5
python codex/install.py --skills-dir <каталог-навыков> --only mac
```

Предыдущие навыки сохраняются в соседнем `skill-backups`. Имеющийся `mac/settings.json` сохраняется при обновлении. Проверьте, что Codex обнаружил навыки; при необходимости откройте новый чат. Маршруты коротких команд можно взять из [AGENTS.fragment.md](AGENTS.fragment.md), сохранив остальные свои инструкции.

## Начало проекта

Откройте папку своего проекта в Codex и попросите:

> Используй CD5 для этой задачи: [цель и ожидаемый результат]. Настрой память проекта, сохрани ограничения. Разрешаю начать работу в этом объёме.

Штаб создаёт или подхватывает проектную конфигурацию и ведёт работу. Для новой памяти используются пять файлов: `OUTLINE.md`, `CHECKPOINT.json`, `EVIDENCE.jsonl`, `KNOWLEDGE.jsonl`, `ATTENTION.jsonl`. Их расположение задаёт `.cd5/config.json`. Новый технически инициализированный проект начинается с остановки до явного разрешения пользователя.

У существующего проекта нужно сохранить прежнюю память, владельца, ограничения и остановки. Установка навыка не является разрешением продолжить остановленную работу. Дальше достаточно обычного **«Продолжай работу»** в чате штаба.

## Прогресс и расход

```text
Покажи прогресс
Покажи прогресс за неделю
Покажи прогресс за всё время
```

Отчёт начинается со свежих десяти CU и позволяет листать выбранную историю без новых запросов к модели. Подробности задачи, результата и команды раскрываются локально. Итог относится ко всей выбранной истории, не только к видимой странице.

CU объединяет работу в полезный для контроля результат. Прогноз WU задаётся диапазоном с уверенностью; исходный прогноз и изменения сохраняются. Факт собирается кодом из журналов. Лимит — отдельная необязательная настройка, не верхняя граница прогноза. Лимиты можно вообще не назначать. Подробная семантика: [WU budgets](skills/cd5/references/wu-budgets.md).

Два коротких действия штаба — начало CU и существующий короткий результат — позволяют коду сохранить привязку к ходу. Не нужно писать отдельный бухгалтерский отчёт. Сбор происходит при чтении прогресса, а не фоновыми обращениями к модели. Подробности: [automatic usage](skills/cd5/references/automatic-usage.md).

Общий расход команды остаётся неполным, если независимость родительских и дочерних счётчиков не подтверждена. Само родство агентов не доказывает независимость. Отсутствие данных не превращается в нулевую стоимость; последний ход может ещё дописываться. WU не показывает доступный баланс подписки.

## MAC

```text
MAC auto
MAC off
MAC status
```

`auto` разрешает полезное ограниченное делегирование; простую работу штаб делает сам. `off` запрещает необязательное делегирование. Команды CD5 `on/off/status` управляют только CD5. Конкретные модели выбираются из доступных в вашей среде; персональные настройки не распространяются вместе с комплектом.

## Посмотреть пример без проекта

Из корня репозитория:

```sh
python codex/examples/build_report.py
```

Откройте `codex/docs/examples/progress-report.html`. Это офлайн-отчёт настоящего генератора на вымышленных данных. Он не читает локальные сессии, не создаёт CU в вашем проекте и не вызывает модель. PNG в основном README — отдельно помеченная иллюстрация того же интерфейса, не скриншот реального проекта.

## Внести изменения

Иллюстрация воспроизводится командой `python codex/examples/render_illustration.py` (SVG, стандартная библиотека). Дополнительный флаг `--png` создаёт PNG и требует Pillow; это необязательная зависимость только для перерисовки картинки. Самим навыкам, тестам установки и генератору HTML она не нужна.

1. Редактируйте `codex/skills/<имя-навыка>` в этом репозитории.
2. Запустите `python codex/run_tests.py`.
3. При изменении отчёта пересоберите пример и обновите иллюстрацию.
4. Закоммитьте изменения; установите проверенную версию через `codex/install.py`.

Старая проектная сборка, которая копировала файлы из внешней папки `tools`, здесь не используется. Установленный каталог — рабочая копия, а этот Git-репозиторий — источник разработки. Не добавляйте пользовательскую память, реальные журналы, секреты и локальные настройки моделей.
