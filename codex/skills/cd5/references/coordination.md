# CD5 coordination

Delegation is optional. The primary owner may work alone when a separate result would not materially help. If delegation helps, use the available native subagent mechanism and any enabled MAC settings. CD5 remains usable when MAC is off; mandatory project rules and existing user authorization still apply.

When MAC is installed, resolve its settings through its own `scripts/mac_settings.py`; the script defaults to its containing skill directory. Treat `auto` and `off` as one mode. Read it before an optional assignment and before each helper launch; off disables optional delegation. MAC is not required for CD5 single-owner work. If delegation is requested but the native tool or MAC is unavailable, state that limit and continue useful single-owner work within authorization.

The root primary may directly launch executor, reviewer, consultant, or helper roles. A main role (executor, reviewer, or consultant) may directly launch bounded helpers within its assignment and shared budget. Helpers never delegate. Maximum depth is primary → main role → helper. Only the root primary launches reviewer and consultant roles. Do not route a main role's permitted helper through the primary. If the platform disallows a permitted nested call, report that limit.

Keep the primary unchanged as owner of scope, integration, and consequential decisions. Choose model and effort from the current environment and local settings; do not claim a model that is unavailable or silently substitute one. An agent role does not grant permissions. Give each assignment a bounded goal, verified context, constraints, expected result, check, write scope, and budget. Helpers consume the caller's existing budget.

The primary checks every returned result. Call a check independent only when a separate reviewer actually examined the work; otherwise call it a self-check. Agent advice and user-interface activity are not human gold. Preserve unknown measurements as unknown and do not add parent-inclusive and child usage totals when their scopes overlap or are unverified.
